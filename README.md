# GSQ — Веб-сайт ванильного сервера Minecraft

Стильный, минималистичный сайт в чёрно-белых тонах с неоновым свечением (glow-эффектами), разработанный на базе React + TypeScript + Tailwind CSS + Lucide Icons.

---

## 🧭 Навигация и разделы

1. **Главная (`/`)**:
   - Логотип GSQ в сверхжирном футуристичном стиле
   - Индикатор онлайна сервера в реальном времени (онлайн, TPS 20.0)
   - Карточка версии игры (**1.21.x**)
   - Карточка IP-адреса (**play.gsq.ru**) с интерактивной анимацией копирования и тултипом *"Скопировано!"*
   - Блоки с ключевыми особенностями сервера (Чистая ванила, Plasmo Voice, CoreProtect, честная экономика на алмазах)
   - Быстрое руководство по подключению

2. **Магазин (`/store`)**:
   - **SUB** — базовая подписка (199 ₽ / навсегда)
   - **SUB+** — максимальные возможности (399 ₽ / навсегда) с отметкой *"Популярный"*
   - Дополнительные услуги:
     - **Разбан** (от 299 ₽)
     - **Размут** (от 199 ₽)
     - **Пожертвование** (от 50 ₽)
   - Интерактивное модальное окно оформления заказа:
     - Автоматическая подгрузка аватарки скина по нику
     - Способы оплаты: СБП (0%), Банковские карты (МИР/Visa/MC), T-Pay / СберPay, Криптовалюта
     - Промокоды (например, промокод `GSQ` даёт 15% скидку)

3. **Правила (`/rules`)**:
   - Фиксированный сайдбар слева с 8 категориями правил
   - **ScrollSpy**: категория в сайдбаре автоматически подсвечивается при скролле страницы
   - Плавный переход к категории при клике на сайдбар
   - Удобный поиск по тексту правил в реальном времени

4. **Карта мира (`/map`)**:
   - Отображение карты во весь экран (iframe для Dynmap, BlueMap, Squaremap, Pl3xMap)
   - Переключение измерений (Обычный мир / Нижний мир / Энд)
   - Полноэкранный режим (Fullscreen), кнопка обновления и открытия в новой вкладке
   - Бейдж *"Карта сервера GSQ"* в правом нижнем углу

## ⚙️ Как изменить ссылку на карту и настройки сервера

Все главные настройки вынесены в один файл:
👉 `src/lib/constants.ts`

### 1. Как вставить свою карту:
В файле `src/lib/constants.ts` в первой строке измените значение `MAP_URL`:
```typescript
export const MAP_URL = 'https://map.your-server.ru'; // ваша ссылка на BlueMap / Dynmap
```

### 2. Как изменить IP, версию и онлайн:
В объекте `SERVER_INFO` в том же файле `src/lib/constants.ts`:
```typescript
export const SERVER_INFO = {
  ip: 'play.gsq.ru',
  version: '1.21.x',
  onlinePlayers: 138,
  maxPlayers: 250,
  // ...
};
```

## 🚀 Команды для запуска

```bash
# Перейти в папку проекта
cd /Applications/gsq-website

# Запуск локального сервера разработки (сайт откроется на http://localhost:3000)
npm run dev

# Сборка проекта для продакшена
npm run build

# Предпросмотр собранной версии
npm run preview
```
